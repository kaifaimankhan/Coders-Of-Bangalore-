# OpenAI Instagram Followers Analysis

## Overview

This project focuses on analyzing Instagram profile data collected from OpenAI-related Instagram accounts. The dataset was manually collected, cleaned, and analyzed using Python and Pandas to extract meaningful insights. The objective of this project was to practice data cleaning, exploratory data analysis (EDA), and data visualization techniques on real-world social media data.

---

## Objectives

- Collect Instagram profile data.
- Clean and organize the dataset.
- Remove duplicate records.
- Handle missing values.
- Perform exploratory data analysis.
- Generate meaningful insights from the dataset.

---

## Dataset

The dataset was manually collected from publicly available Instagram profiles.

### Dataset Includes

- Username
- Followers
- Following
- Posts
- Category

---

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Data Cleaning

The following data cleaning steps were performed:

- Removed duplicate records.
- Handled missing values.
- Standardized column names.
- Converted data into appropriate data types.
- Checked for inconsistencies.
- Prepared the dataset for analysis.

---

## Exploratory Data Analysis

The following analyses were performed:

- Identified the account with the maximum number of posts.
- Identified the account with the maximum number of followers.
- Identified the account with the maximum number of followings.
- Counted the total number of unique categories.
- Generated summary statistics of the dataset.

---

## Key Insights

- Determined the most active Instagram account based on the number of posts.
- Identified the account with the highest follower count.
- Found the account following the highest number of users.
- Analyzed the distribution of profile categories.
- Created a clean dataset for further analysis.

## How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/OpenAI-Instagram-Analysis.git
```

### 2. Move into the Project Folder

```bash
cd OpenAI-Instagram-Analysis
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

### 5. Run the Notebook

Execute all notebook cells to reproduce the complete analysis.
